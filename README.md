# Image Previewer

**Image Previewer** — это HTTP-сервер на Go, который проксирует изображения, изменяет их размер и кэширует результаты на диске для быстрого повторного доступа.


## Функционал

- Проксирование изображений с удалённых URL
- Изменение размера изображений (`width` × `height`)
- Кэширование JPEG-изображений на диске (LRU-кэш)
- Логирование скачивания, обработки и кэширования
- Поддержка динамического конфигурирования порта и размера кэша


## Установка и запуск

1. Клонируем репозиторий:

```bash
git clone git@github.com:krysanov-as/image-previewer.git
cd image-previewer
```

2. Сборка приложения:
```bash
make build
```

3. Запуск:
```bash
./previewer
```

```yaml
Стандартная конфигурация по умолчанию:
Порт: :8080
Кэш-каталог: ./cache
Размер кэша: 100MB
```



Пример запуска с кастомным портом и размером кэша (200мб ,  задаем  в байтах):
```bash
./previewer --port :9090 --cache 209715200
```
